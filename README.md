# As you command

คลังคำสั่ง OOC สำหรับ SillyTavern ที่ติ๊กเปิดหรือปิดได้ทีละข้อ คำสั่งที่เปิดไว้จะถูกแทรกเข้า prompt ใหม่ทุกเทิร์นที่ความลึกคงที่ จึงไม่ถูกประวัติแชทดันหายไปเหมือน OOC ที่พิมพ์ในแชทธรรมดา

## ติดตั้ง

Extensions → Install extension → วางลิงก์นี้

```
https://github.com/inathael-58/SillyTavern-As-you-command
```

## วิธีเปิดแผง

- เมนู 🪄 → **As you command** (มีตัวเลขบอกว่ากำลังเปิดอยู่กี่คำสั่ง)
- พิมพ์ `/ayc`
- Extensions → As you command → ปุ่ม **เปิดแผงคำสั่ง** / **คลัง** / **ตั้งค่า**

- ปุ่มลอยบนจอ (ดูหัวข้อถัดไป)

บนมือถือแผงจะเปิดเต็มจอ มีแถบเมนูอยู่ด้านล่าง ส่วนบนจอกว้างจะเป็นหน้าต่างกลางจอ

## ปุ่มลอย

- **ตัวเลขสีเขียวบนปุ่ม** = จำนวนคำสั่งที่มีผลอยู่ตอนนี้ (ทุกแชท + แชทนี้) ถ้าไม่มีคำสั่งที่เปิดอยู่ ตัวเลขจะซ่อน ถ้าปิดทั้ง extension ปุ่มจะเป็นสีเทา
- แตะ = เปิดแผง · ลาก = ย้าย (ปุ่มจะติดขอบจอที่ใกล้ที่สุด) · **กดค้าง = แต่งหน้าตาปุ่ม**
- แต่งได้แบบเดียวกับ Chat Browser: สไตล์สำเร็จรูป 8 แบบ รูปทรง 9 แบบ (วงกลม มนเหลี่ยม บับเบิล แคปซูล+ข้อความ หัวใจ ดอกไม้ ดาว ก้อนเมฆ สติกเกอร์) ไอคอน อีโมจิ รูปภาพจากเครื่องหรือลิงก์ ขนาด ความทึบ สีพื้น สีไอคอน การเคลื่อนไหว ขอบ เงา และเปิด/ปิดตัวเลข
- เปิด/ปิดปุ่มลอยและแต่งปุ่มได้ที่ แผง → ตั้งค่า → ปุ่มลอย หรือ Extensions → As you command
- เก็บปุ่มเข้า Quick Dock ได้เหมือนปุ่มลอยของ extension อื่น

## แถบเมนูล่าง

| เมนู | ใช้ทำอะไร | เก็บที่ |
|---|---|---|
| 🌐 ทุกแชท | กฎที่ใช้กับทุกบอท ทุกแชท | extension settings |
| 💬 แชทนี้ | กฎหรือทิศทางเนื้อเรื่องเฉพาะแชทนี้ | chat metadata (ติดไปกับไฟล์แชท) |
| 📚 คลัง | คำสั่งสำเร็จรูปยอดนิยม 28 ข้อ + แม่แบบที่สร้างเอง | — |
| ⚙ ตั้งค่า | ตำแหน่งที่แทรก แม่แบบ หน้าตา สำรองข้อมูล เวอร์ชัน | extension settings |

- ตัวเลขบนเมนูคือจำนวนคำสั่งที่เปิดอยู่ ถ้ามี **!** ที่เมนูตั้งค่า แปลว่ามีเวอร์ชันใหม่ที่ยังไม่ได้โหลด
- ปุ่ม **+** มุมขวาล่างใช้เพิ่มคำสั่ง (ในเมนูคลังใช้สร้างแม่แบบ)
- ปุ่ม **⋮** บนการ์ดใช้แก้ไข ย้ายไปอีกขอบเขต บันทึกเป็นแม่แบบในคลัง หรือลบ
- ในเมนูคลัง กด **+ ทุกแชท** หรือ **+ แชทนี้** เพื่อเพิ่มและเปิดคำสั่งทันที ถ้าคำสั่งนั้นอยู่ในลิสต์แล้ว ปุ่มเดียวกันใช้สลับเปิด/ปิด
- คำสั่งที่เขียนเอง ติ๊ก "บันทึกเป็นแม่แบบในคลังด้วย" ไว้ เพื่อเก็บไว้ใช้กับแชทอื่นในภายหลัง

## ตัวเลือกของแต่ละคำสั่ง

- **ใช้ครั้งเดียว ⚡**: ปิดตัวเองหลังบอทตอบ 1 ข้อความ เหมาะกับคำสั่งอย่างข้ามเวลา เปลี่ยนฉาก หรือหักมุม เมื่อคำสั่งมีผลแล้วจะมีป๊อบอัพเล็กๆ บอกว่าคำสั่งไหนถูกปิดไปแล้ว **แตะที่ป๊อบอัพเพื่อเปิดคำสั่งนั้นกลับมา** เช่น ก่อนจะ swipe (ปิดป๊อบอัพนี้ได้ในหน้าตั้งค่า)
- **กลุ่ม**: คำสั่งในกลุ่มเดียวกันเปิดได้ทีละอัน เช่น `length` (ตอบสั้น/ตอบยาว) `pace` `pov` เมื่อเปิดอันใหม่ อันเก่าจะปิดเองทั้งในแท็บทุกแชทและแท็บแชทนี้
- **ลากเรียงลำดับ**: ลากที่ไอคอน ⠿ ด้านซ้ายของการ์ด ลำดับในลิสต์คือลำดับที่ส่งให้โมเดล โดยคำสั่งจากทุกแชทจะมาก่อนคำสั่งจากแชทนี้
- ใช้ macro `{{char}}` และ `{{user}}` ในข้อความคำสั่งได้

## ตั้งค่า (เมนู ⚙ ในแถบล่าง)

- **ตำแหน่ง**: ค่าเริ่มต้นคือในแชท @ ความลึก 2 role System
  - depth 0 แรงที่สุด แต่บอทอาจตอบสนองต่อคำสั่งตรงๆ
  - depth 2–4 สมดุลที่สุด
- **แม่แบบห่อ**: ข้อความที่ห่อรายการคำสั่ง โดย `{{list}}` คือตำแหน่งที่รายการถูกวาง
- **แจ้งเมื่อคำสั่งใช้ครั้งเดียวมีผลแล้ว**: เปิดไว้เป็นค่าเริ่มต้น
- **ไม่ส่งตอน generate เบื้องหลัง**: เปิดไว้เป็นค่าเริ่มต้น เพื่อไม่ให้ OOC ปนเข้าไปใน quiet prompt ของ extension อื่น เช่น งานสรุปความจำ
- **หน้าตา**: ตามธีม ST / สว่าง / มืด
- **ส่งออก/นำเข้า**: สำรองลิสต์ทุกแชทและคลังของฉันเป็นไฟล์ JSON
- **เวอร์ชัน**: ดูเวอร์ชันที่รันอยู่ ตรวจเวอร์ชัน และ **โหลดเวอร์ชันล่าสุด** (ดูหัวข้อถัดไป)
- ปุ่ม 👁 บนหัวแผงแสดงข้อความที่จะถูกส่งให้โมเดลจริง (แทนค่า macro แล้ว) พร้อมจำนวนโทเคนโดยประมาณ

## อัปเดตแล้วแต่ยังเป็นเวอร์ชันเก่า?

หลังกด Update ใน ST เบราว์เซอร์ (โดยเฉพาะมือถือและเว็บแอปบนหน้าจอโฮม) มักยังใช้ไฟล์เก่าที่จำไว้ As you command จะเทียบเวอร์ชันที่รันอยู่กับไฟล์ที่ติดตั้งบนเซิร์ฟเวอร์ ถ้าบนเซิร์ฟเวอร์ใหม่กว่าจะมีป๊อบอัพให้แตะเพื่อโหลดใหม่ หรือกด **โหลดเวอร์ชันล่าสุด** ได้เองจาก Extensions → As you command หรือหน้าตั้งค่าในแผง ปุ่มนี้ดึงไฟล์ของ extension ใหม่ทั้งหมดแล้วโหลดหน้าใหม่ให้

## Slash commands (ใช้กับ Quick Reply ได้)

```
/ayc                                  เปิดแผง
/ayc-on ตอบสั้น                        เปิดตามชื่อ (ตรงทั้งหมดหรือบางส่วนที่ไม่ซ้ำ)
/ayc-off ตอบสั้น
/ayc-toggle Slow burn
/ayc-on scope=chat ฝนตก                ค้นเฉพาะแท็บแชทนี้
/ayc-add once=true ให้ฝนตกในฉากถัดไป    เพิ่มแล้วเปิดทันที (ค่าเริ่มต้นเก็บในแชทนี้)
/ayc-add scope=global title=กฎโลก ...
/ayc-clear scope=chat                 ปิดทุกคำสั่ง (global | chat | all)
```

## หมายเหตุ

- ข้อความคำสั่งในคลังสำเร็จรูปเขียนเป็นภาษาอังกฤษเพื่อประหยัดโทเคน และให้โมเดลส่วนใหญ่ตีความได้แม่น ส่วนชื่อและคำอธิบายเป็นภาษาไทย แก้เป็นภาษาไทยเองได้หลังเพิ่มเข้าลิสต์
- เปิด/ปิดคำสั่งแล้วกด swipe หรือ regenerate ได้ทันที คำสั่งชุดใหม่มีผลกับข้อความที่กำลังจะสร้าง ไม่ต้องรอเทิร์นถัดไป
- คำสั่งแบบใช้ครั้งเดียวจะปิดเมื่อบอทตอบเสร็จ (swipe ก็นับ) ถ้าจะ swipe ต่อด้วยคำสั่งเดิม ให้แตะป๊อบอัพ ⚡ หรือเปิดใหม่ก่อน swipe
- สีของแผงดึงมาจากธีม ST ที่ใช้อยู่ โดยสีเน้นมาจาก Quote Color ถ้าต้องการกำหนดเอง ใส่ใน Custom CSS ได้ เช่น

```css
#ayc-overlay { --ayc-accent: #c9a96e; }
```
